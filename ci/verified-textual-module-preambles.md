## Admission and freshness

An ordinary C++20 translation unit with buildable module prerequisites may use a textual prefix PCH only when its actual adjusted command equals the immutable project command, the full canonical main scan is observed and non-providing, and a second canonical scan of the lexer-computed prefix at the SAME original main path is complete, error-free and import-free. No import-prefix text heuristics, no input normalization, no directives scanning. Explicit/implicit Clang module-map inputs and PCH inputs decline. Unknown CDB/driver/input provenance declines; current supported memo platform remains Linux.

The proof binds immutable CDB generation, command, environment, exact main/prefix bytes and every recorded filesystem outcome/metadata/content fingerprint. Unique IDs bind the replayed alias partition, preserving immutable-overlay behavior. It does not invent absolute spellings. Headers, drafts, CDB/config/response updates are replayed before reuse; completion also obtains a fresh prefix proof after prerequisite validation. Root62 prerequisite-before-PCH ordering, leases and late semantic validation remain.

The actual PCH compiler's own VFS accesses are independently recorded and replayed before publication. The ASTWriter and ASTReader module managers must both show no imported ASTs. A canonical scan proof alone cannot certify a PCH produced from different bytes. Original still-open compiler File objects are fully read using their OWN descriptor and exact pathname provenance; they are not prematurely closed or replaced with an arbitrary reopened file. Revalidation catches same-size/full-mtime edits and path replacement even while the original descriptor reads old bytes.

An audit nonadmission rejects the candidate and makes exactly one zero-prefix retry with the original compiler invocation and SkipPreambleBuild=true. That flag bypasses textual admission and all text audit recursion, retaining normal module prerequisites and actual semantic completion. Trace fields report the rejected candidate conditions and each invocation's actual skip mode/prefix length. Only audited successful PCHs have TextualModulePreamble=true.
